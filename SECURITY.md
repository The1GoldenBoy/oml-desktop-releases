# Security Policy

## Supported versions

Only the latest published Felix Desktop release is supported with security
updates.

## Reporting a vulnerability

Use this repository's **Security** tab and select **Report a vulnerability** to
send a private report. Do not disclose the issue publicly before it is resolved.

Include the affected version, installer SHA-256, reproduction steps, expected
behavior, and observed behavior. Never attach credentials, secrets, access
tokens, or customer data.

OptimizeMyLife will validate the report, assess its severity, and coordinate a
fix and disclosure when appropriate.
