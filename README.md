# Felix Desktop Releases

This repository contains the official signed Windows release assets for Felix
Desktop by OptimizeMyLife. Application source code is maintained privately.

No installer is published until its signing identity, release gate, checksums,
and provenance have been verified.

Each published release contains:

- `Felix-Setup-<version>.exe`
- `Felix-Setup-<version>.exe.blockmap`
- `latest.yml`
- `SHA256SUMS-public-signed.txt`
- `release-gate-public-signed.json`

Verify the installer hash against `SHA256SUMS-public-signed.txt` before running
it. Official product downloads are linked from
[optimizemylife.ai](https://optimizemylife.ai).

## Security

Report vulnerabilities through GitHub private vulnerability reporting. Do not
publish credentials, customer data, or security details in a public discussion.
See [SECURITY.md](SECURITY.md) for the reporting policy.
